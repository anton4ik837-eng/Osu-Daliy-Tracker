# Подготовка подписи osu! Daily Tracker Alpha

Сборка Alpha намеренно останавливается, пока не настроена постоянная подпись APK. Не добавляйте файл keystore или пароли в Git-репозиторий.

## Требуемые GitHub Actions Secrets

В репозитории откройте **Settings → Secrets and variables → Actions → New repository secret** и создайте:

- `ANDROID_KEYSTORE_BASE64` — содержимое keystore в Base64.
- `ANDROID_KEYSTORE_PASSWORD` — пароль keystore.
- `ANDROID_KEY_ALIAS` — alias ключа.
- `ANDROID_KEY_PASSWORD` — пароль ключа.

Keystore нужно создать один раз в доверенной среде и хранить резервную копию в безопасном месте. Не присылайте keystore и пароли в чат и не коммитьте их в репозиторий. Потеря ключа подписи помешает обновлять будущие APK поверх уже установленных.

## Важное про переход с 0.4.0-prealpha

Предыдущие релизы собирались через `assembleDebug` на GitHub-hosted runner без настроенного постоянного ключа. Это означает, что подпись может отличаться между запусками. Подпись APK не позволяет восстановить закрытый ключ из самого APK. До первого Alpha-релиза необходимо проверить сертификат установленной сборки и определить, потребуется ли однократная переустановка. После настройки постоянного ключа все следующие версии должны использовать только его.

## Нумерация

Alpha устанавливает `versionCode 10000` и `versionName 1.0.0-alpha`. Для каждого последующего APK `versionCode` нужно увеличивать.
