# Replay AI · 2.2.0 Beta

- Текущий встроенный анализатор остаётся эвристическим прототипом с фиксированными весами; он не считается обученной моделью.
- Добавлен экспорт обезличенных числовых признаков текущего полного анализа в JSON для приватного обучающего датасета.
- Для Standard дополнительно вычисляется ошибка aim по расстоянию между координатой нажатия и координатой объекта карты.
- Недоступные без карты признаки (например, hit rate на высокой/низкой плотности) экспортируются как null, а не угадываются.
- Добавлен загрузчик обученного артефакта replay-ai-model.json и inference для шести оценок: тайминг, ритм, aim, чтение, стримы и бурсты.
- До появления проверенного артефакта интерфейс продолжает явно показывать эвристический режим.
- Реальное обучение выполняется отдельно в приватном Osu-Replay-Dataset; модель экспортируется в приложение только после независимой проверки test-метрик.
