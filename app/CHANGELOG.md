# 4.6.0

- Добавлены темы с иллюстрациями персонажей: Hoshimi Miyabi и Rimuru Tempest. Фон с персонажем применяется и на странице статистики, и в Replay Lab; цвета подобраны под каждый образ.

# 4.5.0

- На десктопе OAuth-сессия хранится в защищённом хранилище Electron `safeStorage` и больше не пишется в `localStorage` открытым текстом. На Android и в браузере сохраняется прежний механизм с запасным чтением из хранилища страницы.
- Кнопка «Отключить авторизацию» теперь очищает и защищённое хранилище.

# 4.4.1

- Исправлен баг: при переключении на другой реплей предыдущий playback и его музыка теперь останавливаются. Это работает для загрузки из файла, из аккаунта и из локальной библиотеки.

# 4.4.0

- Проверка обновлений больше не зависит от GitHub API: при ответе 403/429 используется публичная лента релизов, поэтому обновления находятся даже при лимите API.
- На десктопе обновление можно скачать и открыть прямо из приложения: кнопка «Скачать и открыть» загружает установщик в папку загрузок и запускает его.
- Worker кеширует публичный токен osu! и повторяет запросы при временных ошибках 429/503 — меньше лишних запросов к API.
- Добавлен скрипт `npm run version:sync`, который синхронизирует версию во всех файлах по `app/package.json`.

# 4.3.0

- Добавлено сравнение двух реплеев на одной карте: таблица метрик, график отклонений и экспорт отчёта. Второй реплей можно взять из файла или из локальной библиотеки.
- В библиотеке реплеев появились поиск, сортировка и фильтр по источнику.
- Горячие клавиши в Replay Lab: пробел — пауза, стрелки влево/вправо — перемотка, вверх/вниз — громкость, M — беззвучие.
- В плеере показываются метаданные реплея (игрок, моды, дата, очки, комбо, попадания).
- Добавлен экспорт анализа в JSON; исправлен сброс выбранного сегмента при загрузке нового реплея.

# 4.2.0
