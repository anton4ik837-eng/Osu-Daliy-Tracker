# 3.3.1

- Упрощён интерфейс Replay Lab: второстепенные разделы свернуты в компактные панели, основной экран стал короче.
- Настройки просмотра автоматически открываются при загрузке карты.

- Добавлена память скинов: загруженный один раз скин сохраняется на устройстве и выбирается из списка в Replay Lab без повторного доступа к файлам телефона.
- Последний использованный скин автоматически восстанавливается при запуске приложения.
