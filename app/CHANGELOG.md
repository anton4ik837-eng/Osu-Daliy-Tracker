# 4.0.4

- Исправлена проверка обновлений: теперь учитываются стабильные релизы с APK/десктопными файлами, а не только беты; для Windows и Linux предлагается подходящий файл.
- Убран лишний символ `\n`, который отображался в настройках тем.
- Исправлено сравнение версий для пререлизов.

# 4.0.3

- Убрано меню `File / Edit / View / Window / Help` в десктопных сборках.
- Вход в osu! на десктопе теперь проходит в отдельном окне внутри приложения:возврат по `osudailytracker://` перехватывается напрямую, без системного браузера и регистрации протокола в ОС.
- Проверка callback-URL ослаблена: принимается любой адрес с протоколом `osudailytracker:`.

- Обновлены версии в заголовке окна, футере и Replay Lab (были старые значения 3.2.2 / 3.1.0).

# 4.0.1

- Исправлен вход в osu! на Windows: десктопное приложение регистрирует протокол `osudailytracker://`, открывает подтверждение во внешнем браузере и принимает возврат с кодом авторизации.
