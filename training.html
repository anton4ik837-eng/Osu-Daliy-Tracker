Ночное обучение

Планировщик добавляет задачу в очередь планшета. Для ночного обучения Termux Agent должен оставаться запущенным.

Ночной профиль: до 400 эпох и 3 попытки. Patience = 0 отключает раннюю остановку; Learning Rate автоматически уменьшается при плато только при включённом Patience. Обучение может занять заметно больше времени; текущий цикл не прерывается по окончании окна. Часовой пояс: Asia/Almaty (UTC+5).
