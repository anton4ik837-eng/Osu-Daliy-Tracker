# Replay fixtures

Upload the test replay and its matching beatmap here so replay rendering can be reproduced.

Recommended files:
- `<name>.osr` — the replay file.
- `<name>.osu` — the exact beatmap difficulty used by that replay, or `<name>.osz` if you are supplying the complete beatmap set.

If the replay is already available from a public osu! beatmap page, include the beatmap URL in a small `.txt` file as well.

Please keep the replay and matching map together in this folder. Do not include account passwords, API keys, or other private credentials.
